## How to redeem an ASICS promo code correctly

ASICS promo codes are entered in the shopping cart, before checkout, and there are formatting rules that trip people up.

The steps, per ASICS's FAQ:

1. Add your items and click **VIEW CART**.
2. Find the **PROMOTION CODE** box below the SUBTOTAL line.
3. Enter the code **in capital letters, including any dashes**.
4. Click **Apply**. If accepted, the discount shows in the TOTAL and next to each eligible product.

Two restrictions worth knowing before you shop:

- **A code cannot be applied after the order is placed.** No customer service rescue, no retroactive discount. If the discount doesn't appear in the cart, don't proceed while hoping for the best.
- Codes must match the specific products they cover. If Apply does nothing, the usual cause is an excluded item in your cart — often new-release or already-marked-down shoes.
